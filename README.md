# Codex小灯（V1.5）

菜单栏状态灯：看着 Codex 干活，附带 Codex 真实用量显示。

## 灯语

- 忙：绿色加粗 `C`，闪烁；面板第二行「工作中 · 已忙 X 分 X 秒」（数字绿色）
- 闲：红色加粗 `C`，常亮；面板第二行「闲置中」
- 菜单栏格式：`C 46% 20:22 / 91%` = 5 小时剩余（+ 重置时刻）/ 本周剩余，60 秒刷新
- 5 小时额度耗尽（0%）时，菜单栏与菜单里的 `0%` **同步黄色呼吸**（同一呼吸帧，周期 2.6 秒）

## 面板长什么样

```
当前任务：抖音发布辅助平台         ← 第一行，整行绿字 15 半粗
工作中 · 已忙 3 分 12 秒           ← 第二行，文字白、两个数字绿（闲=「闲置中」）
────────────────────────
5小时剩余：91% · 20 分钟后重置
本周剩余：96% · 4 天 17 小时后重置
────────────────────────
测试网速
打开 Codex
更换提示音 ▸                      ← 开关 + 16 个音源，点音名即试听并设为当前
────────────────────────
重启 Codex 小灯 🔄   ← 配「循环箭头」图标
退出 Codex小灯 ⊠    ← 配「方框叉」图标（V1.4，与 WB小灯 同款）
```

## 目录

- `源码/Codex小灯.m`：单文件 Cocoa 源码（975 行），本包核心
- `源码/Resources/`：早期头像帧素材，当前 C 字母版暂不依赖
- `开发文档-Codex小灯.md`：完整开发文档（原理、信号地图、实测记录、内嵌源码）

## 编译

```bash
clang -fobjc-arc -framework Cocoa -framework Carbon -o Codex小灯 源码/Codex小灯.m
```

macOS 自带 clang 即可，无需第三方依赖。要打成 .app 再加一个 Info.plist（LSUIElement=true）。

## 运行依赖

- 读取本机 `~/.codex/sessions/` 会话日志判断忙闲
- 读取 `~/.codex/auth.json`（只读，不刷新 token）调 ChatGPT 用量接口显示剩余额度
- 需要能访问 `chatgpt.com` 的网络环境
